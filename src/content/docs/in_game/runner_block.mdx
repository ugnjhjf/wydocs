**符咒**是运行文言编程代码的核心方块，支持 7 个等级，等级越高运行速度越快。

## 使用

### 运行代码

1. **放置符咒** - 将符咒放置在平面上
2. **编辑代码** - **潜行右键**打开代码编辑界面，输入文言编程代码
3. **执行运行** - **直接右键**运行代码

:::tip[提示]
- 按住 Shift 并右键可**打开代码编辑界面**
- 运行时会根据代码执行状态显示不同颜色和亮度的光效
- 代码错误时会显示红色警告
- 在代码编辑界面中，按住 Shift 可查看代码片段的详细信息
:::

## 平台指令

每个符咒程序的基础环境提供以下指令（无需导入）：

| 指令 | 作用 | 语法 | 示例 |
| --- | --- | --- | --- |
| 觀 | 导入附近功能符（或符内携带模块）的函数包 | `吾嘗觀「<模組名>」之書` | `吾嘗觀「算經」之書。` |
| 書 | 输出文字到符咒屏幕 | `書之` | `施「正弦」於一。書之。` |

## 等级系统

符咒分为 7 个等级，等级越高运行速度越快：

| 等级 | 名称 | 运行速度 (步/刻) |
| --- | --- | --- |
| 0 | 基础符 | 1 |
| 1 | 一阶符 | 10 |
| 2 | 二阶符 | 100 |
| 3 | 三阶符 | 1,000 |
| 4 | 四阶符 | 10,000 |
| 5 | 五阶符 | 100,000 |
| 6 | 六阶符 | 1,000,000 |

## 获取方式

- **基础符**：工作台合成（paper ×8 + iron_ingot），或創石答题（paper，PLUS_CHECKER 连答 8 轮）。
- **一阶~六阶符**：工作台无序合成（对应纸 + 墨各 1）；或在創石用同样材料答题直接产出 2 个。

| 符 | 工作台材料 |
| --- | --- |
| 一阶符 | 松清墨 + 松竹纸 |
| 二阶符 | 朱砂墨 + 云篆纸 |
| 三阶符 | 星光墨 + 星辉纸 |
| 四阶符 | 月华墨 + 霜华纸 |
| 五阶符 | 玄武墨 + 凤羽纸 |
| 六阶符 | 冥土墨 + 龙鳞纸 |

:::tip[小知识]
- 符咒在运行时会消耗能量
- 破坏符咒方块会掉落对应的符物品
- 代码会保存在符咒中，即使破坏也会保留
:::

## 状态显示

符咒会通过颜色和亮度显示当前运行状态：

- **不运行** - 灰色，无光源
- **运行中** - 白色，亮度 4
- **空闲等待** - 黄色，亮度 4
- **错误状态** - 红色，亮度 10
