## 指令

:::tip[模块导入]
无需导入（模块名置空，指令直接可用）。
:::

### 天根

- **作用**：谜题底数 a（随机生成，2 ≤ a < 1e9+9）。
- **语法**：`施「天根」`
- **示例**：`施「天根」。書之。`

### 数极

- **作用**：谜题模数，固定为 1e9+9（十亿又九）。
- **语法**：`施「数极」`

### 天机

- **作用**：谜题指数 b。
- **语法**：`施「天机」`

### 天意

- **作用**：答案占位，普通算核恒为 0。
- **语法**：`施「天意」`
- **备注**：玩家须自行算出 天根^天机 mod 数极。

### 書

- **作用**：提交答案——算出 天根^天机 mod 数极 后 `書` 出。
- **语法**：`書<答案>`
- **示例**：`書一千二百三十四。`
- **备注**：答对产能 +1、返回陽，并重新生成谜题；答错返回陰。

## 综合案例

:::note[验证状态]
本案例由文档编写者按总表语法构造，未在游戏内验证。
:::

读取谜题三要素，算出答案后提交：

```text
施「天根」。名之曰「底」。
施「天机」。名之曰「次」。
施「数极」。名之曰「模」。
夫「底」。書之。夫「次」。書之。夫「模」。書之。
```

随后用循环累乘与「所餘幾何」逐次取模（a^b mod p，约需 O(log b) 步），最后 `書<答案>` 提交。产能会存入算核，供附近符咒的「變天」等功能消耗。
