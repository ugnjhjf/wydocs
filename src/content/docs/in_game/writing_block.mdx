## 用途

刻印台的主要作用是对**基础符至六阶符**进行镌刻。未经镌刻的符咒只是普通的物品，只有通过刻印台的处理，才能成为真正可用的法术载体。

### 工作流程

1. **放置符咒**：手持已制作好的符咒，右键点击刻印台放入
2. **打开界面**：潜行状态下（按住 Shift）右键刻印台，打开镌刻界面
3. **编写代码**：在打开的界面中编写文言编程代码
4. **保存镌刻**：完成编写后关闭窗口，代码会自动镌刻到符咒上
5. **取出成品**：再次右键刻印台，取出已镌刻完成的符咒

## 使用技巧

### 界面操作

- **正常右键**：放入或取出符咒物品
- **潜行右键**：打开镌刻编辑界面
- **标题命名**：可以在界面顶部为当前符咒命名，方便识别
- **代码片段**：右侧提供常用代码片段，点击即可插入

### 批量生产

当需要大量相同的符咒时，可以先在刻印台中放入多张符咒，进行一次镌刻后，所有符咒都会拥有相同的代码。
