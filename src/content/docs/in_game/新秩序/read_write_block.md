**文本读写石**读取告示牌或讲台书籍的文本，也可把文本写入告示牌与「书与笔」。

## 获取方式

仅可通过创造模式物品栏（「吾有一術：新秩序」页签）获得，暂无合成配方。

## 指令

:::tip[模块导入]
`吾嘗觀「文本读写」之書。`
:::

除标注外，本方块同时提供物品投掷版（以投掷运行器为上下文）。

### 「读」

- **作用**：读取告示牌或讲台书籍文本。
- **语法**：`施「文本读写」之「读」以<位置(vec3)>。`
- **示例**：`施「文本读写」之「读」以「位」。`
- **备注**：返回字符串列表（告示牌 4 行；讲台书逐页）；目标未加载报错。

### 「写」

- **作用**：写入告示牌或讲台书（书与笔）。
- **语法**：`施「文本读写」之「写」於<位置(vec3)>於<文本列(列)>。`
- **示例**：`吾有一列。名之曰「文」。充「文」以「「第一行」」。`<br>`施「文本读写」之「写」於「位」於「文」。`
- **备注**：返回真/假；告示牌最多 4 行、每行 ≤20 字；书每页 ≤256 字；只能写「书与笔」。

## 综合案例

:::note[验证状态]
本案例由文档编写者按总表语法构造，未在游戏内验证。
:::

读取符咒旁一格的告示牌并打印：

```text
吾嘗觀「文本读写」之書。
吾嘗觀「向」之書。
施「向」於一於零於零。名之曰「位」。
施「文本读写」之「读」以「位」。名之曰「文」。
夫「文」之「一」。書之。
```
