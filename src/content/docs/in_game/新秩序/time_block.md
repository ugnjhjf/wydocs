**时间石**返回系统时间戳、服务器游戏刻与主世界时间。

## 获取方式

仅可通过创造模式物品栏（「吾有一術：新秩序」页签）获得，暂无合成配方。

## 指令

:::tip[模块导入]
`吾嘗觀「时间」之書。`
:::

除标注外，本方块同时提供物品投掷版（以投掷运行器为上下文）。

### 「时间戳」

- **作用**：返回系统时间戳（毫秒）。
- **语法**：`施「时间」之「时间戳」。`
- **示例**：`施「时间」之「时间戳」。名之曰「毫秒」。`
- **备注**：返回數。

### 「游戏刻」

- **作用**：返回服务器游戏时间（tick）。
- **语法**：`施「时间」之「游戏刻」。`
- **示例**：`施「时间」之「游戏刻」。名之曰「刻」。`
- **备注**：返回數。

### 「时间」

- **作用**：返回主世界时间（tick）。
- **语法**：`施「时间」之「时间」。`
- **示例**：`施「时间」之「时间」。名之曰「时刻」。`
- **备注**：返回數（主世界时钟时间）。

## 综合案例

:::note[验证状态]
本案例由文档编写者按总表语法构造，未在游戏内验证。
:::

测量两段代码之间的服务器时间差：

```text
吾嘗觀「时间」之書。
施「时间」之「游戏刻」。名之曰「起」。
為是百遍書一云云。
施「时间」之「游戏刻」。名之曰「止」。
夫「止」。減「起」。書之。
```
