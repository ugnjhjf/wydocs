**方块操作石**从施法者背包放置方块、挖掘指定方块（钻石镐等级）、或互换两处方块。

## 获取方式

仅可通过创造模式物品栏（「吾有一術：新秩序」页签）获得，暂无合成配方。

## 指令

:::tip[模块导入]
`吾嘗觀「方块操作」之書。`
:::

除标注外，本方块同时提供物品投掷版（以投掷运行器为上下文）。

### 「放置」

- **作用**：从施法者背包放置方块。
- **语法**：`施「方块操作」之「放置」以<位置(vec3)>。`
- **示例**：`施「方块操作」之「放置」以「位」。`
- **备注**：成功返回 1，否则 0；消耗背包内方块（创造模式不消耗）；优先搜索快捷栏。

### 「挖掘」

- **作用**：挖掘指定方块（钻石镐等级，掉落）。
- **语法**：`施「方块操作」之「挖掘」以<位置(vec3)>。`
- **示例**：`施「方块操作」之「挖掘」以「位」。`
- **备注**：成功返回 1，否则 0。

### 「互换」

- **作用**：交换两处方块。
- **语法**：`施「方块操作」之「互换」於<位置A(vec3)>於<位置B(vec3)>。`
- **示例**：`施「方块操作」之「互换」於「甲位」於「乙位」。`
- **备注**：成功返回 1，否则 0；容器换容器时 A 向 B 转移物品；容器与普通方块交换时物品原地掉落。

## 综合案例

:::note[验证状态]
本案例由文档编写者按总表语法构造，未在游戏内验证。
:::

互换符咒两侧的方块：

```text
吾嘗觀「方块操作」之書。
吾嘗觀「向」之書。
施「向」於一於零於零。名之曰「甲位」。
施「向」於零於零於一。名之曰「乙位」。
施「方块操作」之「互换」於「甲位」於「乙位」。書之。
```

成功输出 `一`。
