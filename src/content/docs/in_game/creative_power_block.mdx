**創核石**是创造模式专用的能量调试方块，可随意设置「天机」「天意」值。

## 获取方式

暂无合成配方，仅可通过创造模式物品栏获得。

## 指令

:::tip[模块导入]
无需导入（模块名置空，指令直接可用）。
:::

### 天机

- **作用**：设置/读取天机值。
- **语法**：`施「天机」於<數>`
- **示例**：`施「天机」於一千。`

### 天意

- **作用**：设置/读取天意值。
- **语法**：`施「天意」於<數>`
- **示例**：`施「天意」於零。`

## 综合案例

:::note[验证状态]
本案例由文档编写者按总表语法构造，未在游戏内验证。
:::

设置并读回两个调试值：

```text
施「天机」於一千。
施「天意」於零。
施「天机」。書之。施「天意」。書之。
```
