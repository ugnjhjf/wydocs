用于给模块或实体命名的工具。浮签不提供文言指令。

## 使用

右键模块或实体，在弹出的gui上进行命名。
命名时会为名字加上中文引号(「」)，并消耗一点耐久。（耐久回复方式在源码中为 TODO，配方数据中未找到回复配方。）
