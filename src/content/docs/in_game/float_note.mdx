> 书本或文稿内随文粘贴的纸条，上书批注修改或其它需要说明的文字。 <mark>故宫博物院</mark>

用于给模块或实体命名的工具

## 使用

右键模块或实体，在弹出的gui上进行命名。
命名时会为名字加上中文引号(「」)，并消耗一点耐久。耐久可以在工作台用纸回复(TODO)。
