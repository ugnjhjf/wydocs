## 指令

:::tip[模块导入]
`吾嘗觀「炉」之書。`（整包导入）
:::

### 熔

- **作用**：烧炼进度 +1，达到所需进度时自动完成烧炼。
- **语法**：`施「熔」`
- **备注**：需先放入有烧炼配方的原料且进度已知。

### 倍熔

- **作用**：烧炼进度翻倍。
- **语法**：`施「倍熔」`
- **备注**：等于所需进度时正常完成；超过所需进度时原料直接消失。

### 取熔 / 取熔最大

- **作用**：获取当前进度 / 所需总进度。
- **语法**：`施「取熔」`；`施「取熔最大」`

## 综合案例

:::tip[出处]
本案例出自 gameTest（`LogicFurnaceBlockTest.java:101`），已在游戏内验证（导入行为游戏内模块名「炉」）。
:::

先读取进度，逐次熔炼一格，再翻倍：

```text
吾嘗觀「炉」之書方悟「熔」「倍熔」「取熔」「取熔最大」之義。
施「取熔」。書之。施「熔」。施「取熔」。書之。施「倍熔」。施「取熔」。書之。
```

输出当前进度、+1 后的进度与翻倍后的进度。
