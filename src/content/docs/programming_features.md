# 吾有一术（Wenyan Programming）符咒可用指令汇总

由 AI 学习源码后生成（未检查）

> 汇总 **WenyanNature（模组本体）** 当前版本提供给玩家编写符咒的文言函数与常量。
> 数据提取自源码（WenyanNature 仓库 `src/main/java`，函数注册处）与语言文件 `zh_cn.json`，提取日期 2026-08-14（mod 版本 1.0.1，MC 26.1）。

## 调用约定

:::tip[速查与详情]
本表仅作指令速查；每个方块的合成配方、指令详解与综合案例见各节「提供方块」链接。
:::

| 用法 | 语法 |
| --- | --- |
| 导入功能符模块 | `吾嘗觀「<模組名>」之書`（整包导入）；`吾嘗觀「<模組名>」之書方悟「<名>」「<名>」之義`（选择性导入） |
| 调用函数 | `施「<函數名>」於<參數一>於<參數二>…`；零参数可用 `施「<名>」`（「以」「於」均为合法参数连接词） |
| 读取常量 / 零参函数 | `夫「<名>」` |
| 访问对象属性 | `夫<對象>之「<屬性名>」` |
| 输出 | `書之`（打印上一个值），或 `書<值>` |

### 参数类型速查

| 类型 | 含义 |
| --- | --- |
| `數` | 数字 |
| `言` | 字符串（`「「文本」」`） |
| `爻` | 布尔（陰/陽） |
| `列` | 列表 |
| `物` | 对象（`vec3` 位置向量 / `entity` 实体 / `塊` 方块 / `槽` 物品槽） |

### 示例写法约定

示例假定已导入所需模块（如 `吾嘗觀「算經」之書。`）。常用占位写法：

- **「位」— 向量/位置变量**：由「向」模块构造，`吾嘗觀「向」之書。施「向」於<X>於<Y>於<Z>。名之曰「位」。`
- **「群」— 实体列表**：由「实」模块获取，`施「近域之实」於<半径>。名之曰「群」。`
- 数字使用中文数字。
- 功能符（模块方块）需放置在运行方块附近（或作为物品塞进符/投符内），代码中 `吾嘗觀` 导入后即可调用其函数。
- 不同提供方可能提供同名指令（如多个方块都提供 `書`），实际使用哪个取决于该符运行平台所连接的方块。
- 下表「方块注册名」为源码中注册名，完整方块 ID 为 `wenyan_programming:<注册名>`。
- 本表仅覆盖本体（WenyanNature）；附属模组 WenyanAddon 的功能方块见[《吾有一术：新秩序 · 指令总览》](../addon_features/)。
