**數符**提供圆周率、正弦、平方根等数学常数与函数，是符咒计算的基石。

## 获取方式

<Recipe result="math_module_block" items={["", "bamboo_paper", "", "", "copper_ingot", "", "", "bamboo_paper", ""]} />

> 每次合成产出 2 个。物品名省略命名空间：mod 物品为 `wenyan_programming:`，原版物品为 `minecraft:`；`#` 开头为标签（任意匹配物品）。

## 指令

:::tip[模块导入]
`吾嘗觀「算經」之書。`（整包导入）
:::

| 指令 | 作用 | 语法 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| 圓周率 / 倍圓周率 / 半圓周率 / 四分圓周率 / 自然常數 / 歐拉常數 / 黃金分割數 / 二之平方根 / 二之對數 / 十之對數 | 数学常数（π、2π、π/2、π/4、e、欧拉常数、黄金分割比、√2、ln2、ln10） | `夫「<常量名>」` | `吾嘗觀「算經」之書。夫「圓周率」。書之。` | 常量 |
| 正弦 / 餘弦 / 反正弦 / 反餘弦 / 正切 / 反正切 / 對數 / 指數 / 平方根 / 絕對 / 取頂 / 取底 / 取整 / 正負 | 单参数数学函数 | `施「正弦」於<數>` | `施「正弦」於一。書之。` | 取頂=向上取整；取底=向下取整；取整=四舍五入；正負=符号函数 |
| 冪 / 勾股求角 / 勾股求弦 | 双参数数学函数 | `施「冪」於<底數>於<指數>` | `施「冪」於二於十。書之。` | 勾股求角=atan2；勾股求弦=hypot |

## 综合案例

:::note[验证状态]
本案例由文档编写者按总表语法构造，未在游戏内验证。
:::

求 3-4-5 直角三角形的斜边长：

```text
吾嘗觀「算經」之書。
施「算經」之「勾股求弦」於三於四。書之。
```

输出 `五`。
