---
title: "演示二：点石成金"
---

> 借符咒之力，随手改变世界的方块。

用**方块操作石**在指定位置放置、替换、破坏方块。你只需要认识一行「方块 ID」，就能随心所欲地点石成金。

## 你需要摆

```
         东 →
   北
   |
   --- 方块操作石(2, 0, 0)
   |   符咒(0, 0, 0)     <- 你站这里
   |
   '---- [操作区]（方块操作石以东的格子）
```

- 方块操作石在符咒 3 格以内。
- 脚本里的坐标是**相对方块操作石**的偏移：(1, 0, 0) 表示方块操作石以东 1 格。

## 符咒代码

```text
%% 演示二：点石成金
吾嘗觀「方块操作」之書。   %% 导入方块操作石的功能包

%% ① 在方块操作石以东 1 格放置金块
%%    参数依次是：x、y、z 相对偏移、方块 ID
施「置」於一於零於零於「「minecraft:gold_block」」。

%% ② 把刚才的金块替换成钻石块（尽量保留原方块状态）
施「替」於一於零於零於「「minecraft:diamond_block」」。

%% ③ 破坏它
施「破」於一於零於零。
```

运行后，你会看到方块操作石东侧依次出现金块、变成钻石块、最后消失。

## 改字就变

核心就是**方块 ID**。把所有 `「「minecraft:xxx_block」」` 里的 `xxx_block` 换成你想放的方块：

| 想要的效果 | 方块 ID |
|-----------|---------|
| 金块 | `minecraft:gold_block` |
| 钻石块 | `minecraft:diamond_block` |
| 下界合金块 | `minecraft:netherite_block` |
| 红石块 | `minecraft:redstone_block` |
| TNT | `minecraft:tnt` |
| 原木 | `minecraft:oak_log` |
| 石砖 | `minecraft:stone_bricks` |

方块 ID 的格式为 `模组名:方块名`。原版方块都是 `minecraft:` 开头。ID 写错时，置/替会返回 0（失败），不会报错，也不会放错方块。

## 试试看

**盖一面墙**（改变坐标，多放几块）：

```text
吾嘗觀「方块操作」之書。
施「置」於一於零於零於「「minecraft:stone_bricks」」。
施「置」於一於零於一於「「minecraft:stone_bricks」」。
施「置」於一於零於二於「「minecraft:stone_bricks」」。
```

**搭一座塔**（把 y 坐标改大）：

```text
吾嘗觀「方块操作」之書。
施「置」於一於零於零於「「minecraft:glass」」。
施「置」於一於一於零於「「minecraft:glass」」。
施「置」於一於二於零於「「minecraft:glass」」。
```

## 会出错吗

- 方块 ID 写错：不会报错，但什么都不发生（返回 0）。对照上表检查拼写。
- 想放自己不认识的方块：先在创造模式拿起该方块，看看它的 ID 提示。
- 超出可编辑范围：方块操作石只能操作它周围不远的位置，太远则无效。
