> 光与声，皆可挥洒。

让**粒子石**在周围喷出彩色光点，同时让**音符石**奏响音符盒的声音。这是最简单的演示，只需改数字，即可获得截然不同的效果。

## 摆法
![摆法](pictures\case1.png)

- 1x 音符石
- 1x 粒子石
- 1x 任意等级的符咒

## 符咒代码

潜行右键符咒，把下面内容原样抄入代码编辑器：

```text
吾嘗觀「粒子」之書。
吾嘗觀「奏」之書。

為是二遍。
    
    施「粒子」之「粒子放出」於二百五十五於八十於八十於十二。
    施「奏」之「奏乐」以六。
    
    施「粒子」之「粒子放出」於二百五十五於二百一十五於零於十二。
    施「奏」之「奏乐」以十。
    待一。


    施「粒子」之「粒子放出」於八十於二百五十五於一百二十於十二。
    施「奏」之「奏乐」以十三。
    待一。

 
    施「粒子」之「粒子放出」於八十於一百六十於二百五十五於二十。
    施「奏」之「奏乐」以十八。
    待二。
云云。
```

抄好后直接右键符咒运行。

## 解释

```c
吾嘗觀「粒子」之書。 //导入“粒子石”的功能
吾嘗觀「奏」之書。  //导入“音符石”的功能

為是二遍。 // 执行下方的内容两次
    
    施「粒子」之「粒子放出」於二百五十五於八十於八十於十二。   
    // 粒子石.粒子放出(255, 80, 80, 12);
    // 4 位 rgb值代表颜色。
    // 最后 1 位代表粒子数量。

    施「奏」之「奏乐」以六。
    // 奏.奏乐(6);
    // 1 位 音高。
    // 音高范围是 0～24，6 大约对应 C 音。数值越大，音调越高。

    施「粒子」之「粒子放出」於二百五十五於二百一十五於零於十二。
    施「奏」之「奏乐」以十。
    待一。


    施「粒子」之「粒子放出」於八十於二百五十五於一百二十於十二。
    施「奏」之「奏乐」以十三。
    待一。

 
    施「粒子」之「粒子放出」於八十於一百六十於二百五十五於二十。
    施「奏」之「奏乐」以十八。
    待二。
云云。 // 执行上方的内容两次
```

## 常见问题

- 数字超出范围：颜色超过 255 或数量超过 20，会报参数错误。改成范围内的数字即可。
- 提示找不到「粒子」/「奏」：粒子石或音符石不在符咒 3 格内。
