> 纸上得来终觉浅，绝知此事要躬行。

本系列演示面向**完全不会编程**的玩家：你不需要懂任何编程知识，只需**照抄符咒代码**，再**改几个数字或文字**，就能体验《吾有一术》附属模组（WenyanAddon）的强大功能。

每一个演示都是完整的「使用场景」，通常组合了**多个功能方块**。把方块按图示摆好，抄入代码，右键运行，即可观看效果。

:::note[前置条件]
- 需要安装本体 [WenyanNature] 与附属模组 [WenyanAddon] 。
- 本系列演示使用了 WenyanAddon 的功能方块（粒子石、方块操作石、流体石、交感石、时间石、投射石、数据磁盘、文本读写石等），以及本体的**符咒**与**向量符**。
- 本文档使用简体中文书写，但模组内的包名与函数名必须**原样照抄**，不可自行改成简体或繁体，以免找不到功能。
:::
[WenyanNature]: https://github.com/gyxx-xc/WenyanNature
[WenyanAddon]: https://github.com/gyxx-xc/WenyanAddon

## 三步上手

1. **摆方块**：按照每个演示的示意图，把符咒和功能方块摆出来。
2. **抄代码**：SHIFT + 右键**符咒**打开代码编辑器，把演示的「符咒代码」原样抄进去。
3. **运行**：直接右键符咒，即可看到效果。

:::tip[小贴士]
- 所有功能方块必须放在符咒的 **3 格以内**（可在配置中修改 `runnerRange`，范围 1~5）。
- 功能方块的坐标参数通常都是**相对该功能方块**的偏移（演示六的文本读写除外，它使用世界坐标）。
- 代码编辑器里可以直接点击功能方块提供的**代码片段**，避免手打出错。
:::

## 常见问题

- **报错「包已注册」**：同一功能方块重复出现在一个符咒的 3 格范围内。请确保只有一套方块。
- **报错「距离太远」**：投射类功能的瞄准点超出了功能方块 3 格。
- **功能无效**：先确认功能方块确实在符咒 3 格内，且抄写的包名/函数名和演示完全一致。
