**信號量石**提供获取/释放锁，让多个符咒程序互斥地访问共享资源。

:::caution[模块名冲突]
信號量石与天下情報符的模块名同为「信」。两者同时靠近运行方块时，实际导入哪个取决于平台所连接的方块——请勿将两者同时放在同一符咒 3 格范围内。
:::

| 釋放 | 释放锁（仅持锁者可释放） | `施「釋放」` | `施「釋放」` | |

## 综合案例

:::tip[出处]
本案例出自 gameTest（`LockModuleBlockTest.java:33`），已在游戏内验证（此处按包名限定写法改写，原文调用无包名）。
:::

两个符咒程序先后打印，锁保证互斥。把以下两段分别写入两个符咒并同时运行：

```text
施「信」之「獲取」。為是五遍書一云云。施「信」之「釋放」。
```

```text
施「信」之「獲取」。為是五遍書二云云。施「信」之「釋放」。
```

输出为完整的「一一一一一」与「二二二二二」，不会被交错打断。
