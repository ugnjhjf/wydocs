**阵眼**按名称启动周围的符（运行方块）、查询其状态、等待全部结束，还能在指定符上执行函数——是符咒集群的总指挥。

## 指令

:::tip[模块导入]
`吾嘗觀「眼」之書。`（整包导入）
:::

### 啓

- **作用**：启动指定名称的符（运行方块）。
- **语法**：`施「啓」以「「<符名>」」`
- **示例**：`施「啓」以「「a」」以「「b」」施「歸」`
- **备注**：可在配置范围内查找；可一次启动多个。

### 狀

- **作用**：查询指定符的运行状态。
- **语法**：`施「狀」以「「<符名>」」`
- **示例**：`施「狀」以「「a」」。書之。`
- **备注**：返回 running / idle / error / not_running。

### 歸

- **作用**：等待所有已启动的符执行完毕（阻塞）。
- **语法**：`施「歸」`

### 執

- **作用**：在指定符上执行一个函数。
- **语法**：`施「執」於<符>於<術>`
- **备注**：符为符咒（运行方块）对象。

## 综合案例

:::tip[出处]
本案例出自 gameTest（`FormationCoreModuleBlockTest.java:96`），已在游戏内验证。
:::

启动名为「a」「b」的两个符并等待它们全部运行完毕：

```text
施「啓」以「「a」」以「「b」」施「歸」
```

摆法：阵眼 + 至少两个已命名（符名分别为 a、b）的符咒/运行方块，放在阵眼的范围内。
