**阻塞隊列符**提供一个容量 10 的先进先出队列，多个符咒程序可用它安全地传递数据、协调工作。

## 获取方式

<Recipe result="blocking_queue_module_block" items={["", "starlight_paper", "", "", "hopper", "", "", "starlight_paper", ""]} />

> 每次合成产出 2 个。物品名省略命名空间：mod 物品为 `wenyan_programming:`，原版物品为 `minecraft:`；`#` 开头为标签（任意匹配物品）。

## 指令

:::tip[模块导入]
`吾嘗觀「佇列」之書。`（整包导入）
:::

| 指令 | 作用 | 语法 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| 入 | 元素入队（队满阻塞） | `施「入」於<值>` | `吾嘗觀「佇列」之書。施「入」以一。` | 容量 10；示例出自 gameTest |
| 取 | 元素出队（队空阻塞） | `施「取」` | `施「取」。書之。` | 返回队首元素 |
| 試入 | 尝试入队（非阻塞） | `施「試入」於<值>` | `施「試入」以一。書之。` | 成功返回陽，队满返回陰 |
| 試取 | 尝试出队（非阻塞） | `施「試取」` | `施「試取」。書之。` | 队空返回空 |
| 窺 | 查看队首但不取出 | `施「窺」` | `施「窺」。書之。` | |
| 長 | 队列当前大小 | `施「長」` | `施「長」。書之。` | |
| 清空 | 清空队列并唤醒等待的生产者 | `施「清空」` | `施「清空」。` | |

## 综合案例

:::tip[出处]
本案例出自 gameTest（`BlockingQueueModuleBlockTest.java:38-40`），已在游戏内验证（测试中导入名「1」为测试专用，游戏内为「佇列」）。
:::

入队一个元素再取出：

```text
吾嘗觀「佇列」之書方悟「長」「試取」「入」「試入」「窺」「取」「清空」之義。
施「入」以一。施「取」。書之。
```

输出 `一`。多个程序可以用「入」「取」实现生产者-消费者协作。
