**阻塞隊列符**提供一个容量 10 的先进先出队列，多个符咒程序可用它安全地传递数据、协调工作。

## 指令

:::tip[模块导入]
`吾嘗觀「佇列」之書。`（整包导入）
:::

### 入

- **作用**：元素入队；队满时阻塞等待。
- **语法**：`施「入」於<值>`
- **示例**：`施「入」以一。`

### 取

- **作用**：元素出队（返回队首）；队空时阻塞等待。
- **语法**：`施「取」`
- **示例**：`施「取」。書之。`

### 試入 / 試取

- **作用**：非阻塞入队 / 出队。
- **语法**：`施「試入」於<值>`；`施「試取」`
- **示例**：`施「試入」以一。書之。`
- **备注**：試入成功返回陽、队满返回陰；試取队空返回空。

### 窺 / 長 / 清空

- **作用**：查看队首但不取出；队列当前大小；清空队列并唤醒等待的生产者。
- **语法**：`施「窺」`；`施「長」`；`施「清空」`
- **示例**：`施「長」。書之。`

## 综合案例

:::tip[出处]
本案例出自 gameTest（`BlockingQueueModuleBlockTest.java:38-40`），已在游戏内验证（测试中导入名「1」为测试专用，游戏内为「佇列」）。
:::

入队一个元素再取出：

```text
吾嘗觀「佇列」之書方悟「長」「試取」「入」「試入」「窺」「取」「清空」之義。
施「入」以一。施「取」。書之。
```

输出 `一`。多个程序可以用「入」「取」实现生产者-消费者协作。
