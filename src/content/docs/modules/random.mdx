**熵符**提供随机整数、分数、三角形分布与随机布尔的生成，为符咒引入不确定性。

## 指令

:::tip[模块导入]
`吾嘗觀「易經」之書。`（整包导入）
:::

| 指令 | 作用 | 语法 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| 占數 | 随机整数 | `施「占數」`；`施「占數」於<上界>`；`施「占數」於<下界>於<上界>` | `吾嘗觀「易經」之書。施「占數」於一百。書之。` | 0~2 个参数 |
| 占分 | 0.0~1.0 随机分数 | `施「占分」` | `施「占分」。書之。` | |
| 占偏 | 三角形分布随机数（中心±范围） | `施「占偏」於<中心>於<範圍>` | `施「占偏」於五十於五。書之。` | |
| 占爻 | 随机布尔值 | `施「占爻」` | `施「占爻」。書之。` | |

## 综合案例

:::note[验证状态]
本案例由文档编写者按总表语法构造，未在游戏内验证。
:::

投一枚百面骰，掷出大数则庆贺：

```text
吾嘗觀「易經」之書。
施「易經」之「占數」於一百。名之曰「骰」。
若「骰」大於九十者書「「大吉」」云云。
```
