## 指令

:::tip[模块导入]
`吾嘗觀「易經」之書。`（整包导入）
:::

### 占數

- **作用**：生成随机整数。无参数：任意整数；一个参数：0 到指定数之间的整数；两个参数：指定范围内的整数。
- **语法**：`施「占數」`；`施「占數」於<上界>`；`施「占數」於<下界>於<上界>`
- **示例**：`施「占數」於一百。書之。`

### 占分

- **作用**：生成 0.0 到 1.0 之间的随机分数。
- **语法**：`施「占分」`
- **示例**：`施「占分」。書之。`

### 占偏

- **作用**：生成三角形分布的随机数（中心±范围）。
- **语法**：`施「占偏」於<中心>於<範圍>`
- **示例**：`施「占偏」於五十於五。書之。`

### 占爻

- **作用**：生成随机爻（布尔值）。
- **语法**：`施「占爻」`
- **示例**：`施「占爻」。書之。`
