**爆裂符**召唤闪电、制造爆炸、点燃方块、发射火球，是攻击与破坏类法术的核心。

## 指令

:::tip[模块导入]
`吾嘗觀「爆」之書。`（整包导入）
:::

| 指令 | 作用 | 语法 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| 雷 | 在符咒位置召唤闪电 | `施「雷」` | `吾嘗觀「爆」之書。施「雷」。` | |
| 爆 | 在符咒位置产生爆炸 | `施「爆」於<半徑>` | `施「爆」於三。` | 半径 0~10（内部限幅 0~1000），破坏方块 |
| 燃 | 点燃相对偏移位置的方块 | `施「燃」於<偏移向量>` | `施「燃」於「位」。` | |
| 火球 | 按速度向量发射大火球 | `施「火球」於<速度向量>` | `施「火球」於「位」。` | |

## 综合案例

:::note[验证状态]
本案例由文档编写者按总表语法构造，未在游戏内验证。
:::

向东水平发射一枚火球：

```text
吾嘗觀「爆」之書。
吾嘗觀「向」之書。
施「向」於一於零於零。名之曰「速」。
施「火球」於「速」。
```

火球会沿东方向飞行。
