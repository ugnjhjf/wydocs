**向量符**提供三维向量的构造、方向常量与分量、长度、偏移等运算，是表示位置与方向的通用类型。

## 指令

:::tip[模块导入]
`吾嘗觀「向」之書。`（整包导入）
:::

### 向（构造向量）

- **作用**：用三个数构造向量，或复制一个已有向量。亦为向量类型名。
- **语法**：`施「向」於<x>於<y>於<z>`；或 `施「向」於<向量>`
- **示例**：`施「向」於一於二於三。名之曰「位」。`

### 方向常量

- **作用**：上、下、東、西、南、北（单位向量）与零（零向量）。
- **语法**：`夫「向」之「上」`
- **示例**：`夫「向」之「上」。名之曰「方」。`

### 分量与长度

- **作用**：上下（y 分量）、東西（x 分量）、南北（z 分量）、長（长度）、方長（长度平方）。
- **语法**：`夫<向量>之「上下」`
- **示例**：`夫「位」之「長」。書之。`

### 偏移

- **作用**：向量平移。可加一个向量，或三个数。
- **语法**：`夫<向量>之「偏移」於<向量>`；或 `於<x>於<y>於<z>`
- **示例**：`夫「位」之「偏移」於「方」。書之。`

## 综合案例

:::note[验证状态]
本案例由文档编写者按总表语法构造，未在游戏内验证。
:::

构造两个位置并计算距离平方：

```text
吾嘗觀「向」之書。
施「向」於零於零於零。名之曰「甲位」。
施「向」於三於四於零。名之曰「乙位」。
夫「乙位」之「偏移」於「甲位」。名之曰「差」。
夫「差」之「方長」。書之。
```

输出 `二十五`（3² + 4²）。
