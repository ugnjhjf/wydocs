## 指令

:::tip[模块导入]
`吾嘗觀「文」之書。`（整包导入）
:::

| 指令 | 作用 | 语法 | 示例 | 备注 |
| --- | --- | --- | --- | --- |
| 長 / 反 / 去空 | 字符串长度 / 反转 / 去首尾空白 | `施「長」於<言>` | `吾嘗觀「文」之書。施「長」於「「問天地好在」」。書之。` | |
| 取 | 取第 N 个字符 | `施「取」於<言>於<序號>` | `施「取」於「「問天地好在」」於一。書之。` | |
| 尋 / 包含 / 起始為 / 結束為 | 查找子串 / 判断包含 / 前缀 / 后缀 | `施「尋」於<言>於<子串>` | `施「尋」於「「問天地好在」」於「「天地」」。書之。` | |
| 分 | 按分隔符切分 | `施「分」於<言>於<分隔符>` | `施「分」於「「甲 乙 丙」」於「「 」」。書之。` | 返回列 |
| 換 | 替换子串 | `施「換」於<言>於<舊子串>於<新子串>` | `施「換」於「「問天地好在」」於「「問」」於「「見」」。書之。` | |

## 综合案例

:::note[验证状态]
本案例由文档编写者按总表语法构造，未在游戏内验证。
:::

把「問天地好在」中的「問」替换为「見」，再求长度：

```text
吾嘗觀「文」之書。
施「文」之「換」於「「問天地好在」」於「「問」」於「「見」」。名之曰「新言」。
施「文」之「長」於「新言」。書之。
```

输出 `六`（「見天地好在」共 6 字）。
