## 调用约定

:::tip[速查与详情]
本表仅作指令速查；每个方块的指令详解与综合案例见各节「详情请见」链接。
:::

| 用法 | 语法 |
| --- | --- |
| 导入功能符模块 | `吾嘗觀「<包名>」之書。`（如 `吾嘗觀「投射」之書。`） |
| 调用指令（单参数） | `施「<包名>」之「<指令名>」以<参数>。` |
| 调用指令（多参数） | `施「<包名>」之「<指令名>」於<参数1>於<参数2>。`（「以」「於」均为合法参数连接词） |
| 零参指令 | `施「<包名>」之「<指令名>」。` |
| 输出 | `書之`（打印上一个值） |

### 参数类型速查

| 类型 | 含义 |
| --- | --- |
| `數` | 数字 |
| `言` | 字符串 |
| `爻` | 布尔（陰/陽） |
| `列` | 列表 |
| `物` | 对象（`vec3` 位置向量 / `entity` 实体 / `药效` 药水效果 / `元素` 五行元素 / `图` 键值映射） |

### 示例写法约定

示例均为可直接抄入符咒的代码片段，假定已导入所需包。常用占位写法：

- **「位」— 向量/位置变量**：由「向」模块（向量符）构造，`吾嘗觀「向」之書。施「向」以<X>於<Y>於<Z>。名之曰「位」。`
- **「群」— 实体列表**：由本体「实」模块获取，`施「实」之「近域之实」以<半径>。名之曰「群」。`；取单个实体用 `「群」之「一」`（第一个）。
- **「效」— 药效对象**：由「药」之「取效」返回。
- 数字使用中文数字；字符串用双层括号 `「「文本」」`；布尔用 `陽`／`陰`。
- 除标注外，所有指令同时提供 **方块版**（放置后右键调用，`<位置>` 多数为相对方块的偏移）与 **物品投掷版**（以投掷运行器为上下文）。

- **「染<颜色>」**：染色石共注册 16 条指令，指令名分别为「染白」「染橙」「染品红」「染浅蓝」「染黄」「染黄绿」「染粉」「染灰」「染浅灰」「染青」「染紫」「染蓝」「染棕」「染绿」「染红」「染黑」。
