# 值捕获设计（Design of the Value Capture）

## 先说清楚行为

变量引用在编译期根据词法作用域解析，其目标不因函数在运行时的调用位置而改变。

下面用 Python 当示例语言（注意：只是长得像，行为不完全一样）：

```python
i = 0  # i0

def a():
    # i = i0
    i = 1  # i1
    # i = i1
    if True:
        # i = i1
        i = 2  # i2
        # i = i2

    def b():
        # i = i1
        i = 3  # i3
        # i = i3

# ...

# 如果在这里（a 的外面）调用 b：
# i 仍然引用上面注释里写的那样（i1、i3）
b()
```

要点：**每个「赋值动作」在编译期就确定了它引用的是哪个变量**，而不是运行时去查。

### 可被赋值，且引用跟着变

还需要考虑：变量的**值可以被修改**，而且**所有指向它的引用都会跟着变**。

但是——**当变量被「重新定义」时**，它就开始引用**局部作用域里的新变量**了。

```python
i = 0

def a():
    set
    i = 1  # 也就是「昔之i者 今一是矣」；引用的是 i0
    i = 2  # 也就是「夫二 名之曰i」
    print(i)  # 引用的是 i2

def b():
    print(i)  # 引用的是 i0

a()
b()  # 打印 1
```

> 上面注释里那两行文言，正好对应两种「赋值」：
> - 「昔之i者 今一是矣」→ 把已有的变量 i 改成 1（引用原来的 i0）。
> - 「夫二 名之曰i」→ 定义一个新变量 i = 2（引用局部的新 i2）。

## 设计方案

### 总览

把变量存到**三个部分**里：

| 部分 | 存放内容 | 实现 |
| --- | --- | --- |
| **local（局部）** | 本函数内**定义**的变量 | 帧（frame）里的一个 list |
| **ref（引用）** | 从其他作用域**引用**来的变量 | 帧（frame）里的一个 list |
| **global（全局）** | 全局变量 | 全局作用域里的一个 map（字符串 → 值） |

**编译器**在编译期就把「哪个变量 → local 或 ref list 的哪个下标」算好，运行时直接按下标取值，快得很。

**捕获时机**：当 `make function`（创建函数）时，会把局部作用域里需要用到的变量捕获下来，存在函数（`WenyanBuiltinFunction`）的 list 里。返回时帧会销毁，local list 由 GC 释放；而被引用的值因为存在函数的 list 里，**不会被释放**。之后每次调用这个函数，都会把函数的 list **复制**到新帧的 ref list 里。

### 编译器

编译器要做两件事：

1. **找到变量属于哪个作用域**。
2. **生成对应的指令**。

对于 local 变量，编译器会维护一个**作用域栈**：`Stack of Scope(int stackBase, Map<String, int>)`。

#### 作用域栈

- **进入**作用域：压栈；**退出**：弹栈。
- **查找变量**：从栈顶往栈底找，找到第一个包含该变量的作用域。
- 如果在栈里**都没找到**，就去**父作用域**找，并把它标记为**引用（ref）**。

对于 ref 变量，编译器同样从栈顶往下找。找到后会生成两条记录：`ScopedVar` 和 `CapturedVar`：

- **`ScopedVar`**：变量的「身份标记」。同一个变量再次被加载时，靠它避免被**重复捕获**进 ref list。
- **`CapturedVar`**：记录 ref 的下标。具体怎么设下标，看下面的「指令」一节。

如果**连父作用域都没有**，就把它当**全局变量**处理：存成字符串，运行时去查。

#### 指令生成

**local 的下标**：新变量定义时，`localVariablesCounter++` 并存进 map。作用域退出时，计数**重置为这个作用域的 stackBase**——因为作用域一退出，里面的变量就没用了，之后的新变量可以从 stackBase 开始**覆盖旧位置**。例如：

```python
if True:
    a = 0  # 使用 store 0
b = 1  # 使用 store 0，并覆盖掉旧的变量
```

**ref 的下标**：编译器会记录「需要捕获哪些变量」，形成一个有序的 refs 列表，从而确定每个 ref 在列表里的下标。捕获来源可以是 local，也可以是另一个 ref。如果函数**嵌套定义**，编译器会**沿着父链一层层更新父函数的 refs**，让它们也能加载到这个变量。所以递归捕获时，`CapturedVar` 要做两件事：**第一，把这个变量加进自己的 ref list；第二，把自己在 ref list 里的下标更新返回给父层**。

**全局变量**：字节码维护一张符号表，把字节码里的 int 映射回字符串。

### 运行时

- **make function 时**：把捕获的 refs 存进函数的 ref list。
- **调用时**：新帧的 ref list = 函数的 ref list。

## 总结

值捕获 = 「编译期确定引用，运行时直接按下标取」。变量分 local / ref / global 三块存储；编译器用作用域栈在编译期算好每个变量的下标，创建函数时捕获所需变量、调用时复制到新帧的 ref list。嵌套函数通过沿父链更新 refs 实现逐层捕获，全局变量则靠符号表运行时查找。
