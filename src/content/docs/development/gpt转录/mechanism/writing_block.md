# 刻印台（Writing Block）

刻印台这个方块，是为了解决「改符很麻烦」的问题而生的。先说说背景，你就明白为什么需要它。

## 背景与问题

现在的「符」这个物品，用起来相当复杂——它身上绑了两个操作：**右键**和**Shift + 右键**。

如果玩家想运行一个符，得按下面这串操作来：

1. 按住 Shift；
2. 右键；
3. 松开 Shift；
4. 再右键一次。

该流程步骤较多且容易误操作。设计目标是让符的右键操作只负责使用，将内容编辑迁移到专用方块。

那原来的 Shift + 右键（修改符）功能去哪？答案是放到一个新的方块上——也就是刻印台。因为符本身用得不多，Shift 操作留着反而增加混乱，不如让「改符」变成一件专门的事。

## 刻印台要做什么

### 核心行为

- **右键**：把一整叠符放上去（跟底座一样，但是可以放整叠，而不是只有 1 个）。
- **Shift + 右键**：打开一个编辑 GUI，在里面修改符的内容。

此外需要提供清空符内容的配方，使内容为空的符能够正常参与物品堆叠与合并。

## 总结

刻印台 = 「专门用来写符 / 改符的工作台」。它把原来缠在符物品上的一堆操作拆出来，让符物品只管「跑」，让刻印台只管「写」，各司其职，玩家上手负担更小。

## 设计要点回顾

| 需求 | 做法 |
| --- | --- |
| 简化符的使用 | 符改为仅右键使用，Shift + 右键留给刻印台 |
| 解决大符难以编辑 | 新增刻印台方块，专门提供编辑 GUI |
| 符内容可清理 | 新增清空符内容的配方，方便堆叠合并 |
