# 远程执行协议（Remote Execution Protocol）

## 概述

远程执行协议允许调用方引用另一张符，并让目标符在自身运行环境中执行函数。它与“导入代码后在本地执行”不同：代码、模块和运行状态仍由目标符持有，调用方只提交调用请求并接收结果。

## 处理流程

一次远程调用至少包含以下阶段：

1. **解析目标**：根据引用定位目标符，并验证其仍然有效。
2. **准备执行**：获取或编译目标代码，解析需要调用的函数。
3. **远程运行**：在目标符的调度器和环境中创建执行任务。
4. **返回结果**：将返回值或错误传回调用方，并解除调用方的等待状态。

具体实现必须定义超时、取消、区块卸载、目标移除和异常传播行为。

## 用法示例

```text
target = import("target_fu")
result = exec(target, "function_name")
await(result)
```

该示例表达调用流程，不代表最终文言语法或公开 API。

## 总结

远程执行协议负责打通“定位目标—目标侧执行—结果回传”的完整链路，是阵眼、云端和分布式计算能力的基础。
