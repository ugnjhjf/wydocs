# 阵眼（Formation Core）

## 概述

阵眼是用于统一控制大量符的功能方块。它应提供比逐个导入和调用符更简洁的批量操作接口。

它的定位是：让你**批量管理、调度**多个符，而且操作上要比原来的方式（比如 `import`）**更简单、更直观**。

## 外观

建模已经有了，但还需要加一些游戏内渲染效果，让玩家一眼就看出「这方块很厉害」，比如：

- 展示这个阵眼**能覆盖到的符的范围**。

## 功能

阵眼通过一组文言函数对外提供服务：

| 函数 | 作用 |
| --- | --- |
| `void start(string... fu_name)` | **启动一组符**。覆盖范围要比符本身远一点（`r = 10`） |
| `status status(string fu_name)` | **查询状态**。返回某个被阵眼启动的符的状态，取值有：`not-running`（没在跑）、`running`（运行中）、`error`（出错） |
| `void join()` | **等待**：等所有被阵眼启动的符都跑完 |

符的搜索结果需要缓存，避免每次调用都进行范围扫描。缓存项在方块移除、区块卸载或名称变化后必须重新验证。

## 实现思路

- 维护一个**缓存**：`map<name, pos>`。
- 每次用字符串（符名）时，**先查缓存**，命中就直接用。
- 没命中，**再真的去搜索**（比如在世界里找符），找到后更新缓存。

## 总结

阵眼 = 「符的调度中心」。通过 `start` 批量启动、`status` 查询状态、`join` 等待完成这三板斧，把多符协作变成一条命令的事。实现上靠 `map<name, pos>` 缓存避免重复扫描。
