# 简化合成方块（Simpler Crafting Block）

## 设计目标

这组方块将 Minecraft 的加工流程与函数调用结合，使玩家在获得自动化便利的同时，自然学习参数传递、状态查询和函数组合。

## 设计思路

核心想法是：**用特定的函数逻辑来加速合成**。

不同的方块对应不同的合成场景，每个方块有各自不同的「加速方式」。这一整类方块目前包括：

| 方块 | 加速思路 |
| --- | --- |
| **熔炉（furnace）** | 数学上的「除法」加速 |
| **矿石生成器（ore generator）** | 用「深度优先搜索（DFS）」的方式 |

各方块的具体设计参见：

- 熔炉的详细设计见 [`furnace.md`](../../mechanism/furnace/)。
- 矿石生成器的详细设计见 [`ore_generator.md`](../../mechanism/ore_generator/)。

## 总结

「简化合成方块」是一组设计目标统一的方块家族：它们用文言函数驱动合成，把「函数调用」和「原版合成」揉在一起。熔炉用除法、矿石生成器用 DFS，是这一思路的头两个落地例子。后续如果有新的合成场景，也可以按同样的模式扩展进去。
